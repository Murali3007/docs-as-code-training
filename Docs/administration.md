# User Guide
 
This guide explains the basic tasks that users can perform.
 
## Sign in
 
1. Open the application.
2. Enter your username.
3. Enter your password.
4. Select **Sign in**.
5. want to make some changes and push.
## Create a project
 
1. Open the Projects page.
2. Select **Create Project**.
3. Enter the project name.
4. Select **Create**.
 
## Manage a project
 
Project members can update project settings and manage project content.
 
# Administration
 
Administrators can manage users, roles, and system settings.
 
## Manage users
 
Administrators can add, edit, deactivate, and delete users.
 
## Manage roles
 
Use roles to control access to product features.
 
## Manage system settings
 
System settings control application-wide behavior.
